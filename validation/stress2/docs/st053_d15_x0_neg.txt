If an item is authorised then it is accredited. If an item is cleared then it is endorsed. Any accredited item is also a chartered item. Any endorsed item is also a ratified item. If an item is catalogued then it is audited. If an item is registered then it is catalogued. Every chartered item is transferable. Case romeo-03 is registered. If an item is insured then it is licensed. Any certified item is also a bonded item. If an item is audited then it is certified. Any licensed item is also a approved item. All ratified items are authorised items. All approved items are verified items. All verified items are inspected items. Carton mike-02 is not transferable. Any bonded item is also a insured item. Any inspected item is also a cleared item.
