If an item is bonded then it is insured. Any audited item is also a certified item. If an item is verified then it is inspected. All certified items are bonded items. If an item is inspected then it is cleared. Every licensed item is a approved item. Every chartered item is transferable. Every authorised item is a accredited item. Every registered item is a catalogued item. All catalogued items are audited items. Parcel lima-03 is not transferable. Any approved item is also a verified item. If an item is endorsed then it is ratified. If an item is insured then it is licensed. All ratified items are authorised items. Any cleared item is also a endorsed item. All accredited items are chartered items. Parcel lima-03 is registered.
