Depot register

Every ratified item is a authorised item. Bundle alpha-03 is registered. Any endorsed item is also a ratified item. If an item is certified then it is bonded. If an item is bonded then it is insured. If an item is insured then it is licensed. Crate echo-05 is not transferable. All authorised items are accredited items. All licensed items are approved items. Any accredited item is also a chartered item. Every chartered item is transferable. Every approved item is a verified item. Every inspected item is a cleared item. Every audited item is a certified item. If an item is verified then it is inspected. Every registered item is a catalogued item. All catalogued items are audited items. If an item is cleared then it is endorsed.
